## Automation Rules Setup

### 1. Signup Automation

**Trigger:** New subscriber added to LLMs.txt Tool form

**Actions:**
1. Add tags based on use_case field:
   - If use_case = "enterprise" → Add tag "enterprise_user"
   - If use_case = "academic" → Add tag "academic_user"
   - If use_case = "startup" → Add tag "startup_user"
   - If use_case = "personal" → Add tag "personal_user"

2. Add source tag: "llms_txt_tool_signup"

3. Start "LLM Tool Welcome Series" sequence

### 2. Engagement Tracking

**Trigger:** Subscriber opens email

**Actions:**
- Add tag "email_opener" (if not already present)
- If opens 3+ emails in series → Add tag "engaged_subscriber"

**Trigger:** Subscriber clicks link in email

**Actions:**
- Add tag "link_clicker" (if not already present)
- If clicks upgrade link → Add tag "upgrade_interested"

### 3. Behavioral Segmentation

**Trigger:** Tag "upgrade_interested" is added

**Actions:**
- Start "Upgrade Nurture" sequence (shorter 3-email sequence)
- Remove from main welcome series

### 4. Win-Back Campaign

**Trigger:** 30 days after signup + no recent email opens

**Actions:**
- Start "Win-Back" sequence
- Offer special discount (if applicable)

## KIT Dashboard Setup Instructions

### Step 1: Create Custom Fields

In KIT Dashboard → Grow → Forms → Settings:

1. **use_case** (Single Select)
   - Options: enterprise, academic, startup, personal, other

2. **source_page** (Text)
   - Used for tracking

3. **company** (Text)
   - Optional field

### Step 2: Create Tags

Navigate to Subscribers → Tags and create:

- `llms_txt_tool_signup`
- `enterprise_user`
- `academic_user` 
- `startup_user`
- `personal_user`
- `email_opener`
- `engaged_subscriber`
- `link_clicker`
- `upgrade_interested`
- `welcome_series_complete`

### Step 3: Create Email Sequences

1. Go to Automate → Sequences
2. Create "LLM Tool Welcome Series"
3. Add all 7 emails with specified timing
4. Set up triggers and conditions

### Step 4: Set Up Automations

1. Go to Automate → Rules
2. Create rules for each automation described above
3. Test with a sample subscriber
